# Backend Utils Directory (`backend/utils`)

## Responsibilities
- Houses reusable, pure helper functions and utilities used across the backend.
- Kept independent of application state.

## Planned Utilities
- `logger.js`: Formatted console and file logging.
- `response.js`: Helper functions for standardized JSON responses (`successResponse`, `errorResponse`).
- `dateHelper.js`: Match timestamp calculations, countdowns, and toss lock time verifications.
- `oddsCalculator.js`: Virtual credit odds calculation utilities.
