# Backend Controllers Directory (`backend/controllers`)

## Responsibilities
- Handles HTTP request parsing, payload extraction, and response formatting.
- Delegates core business logic to corresponding service modules.
- Returns standardized JSON responses with appropriate HTTP status codes (200, 201, 400, 401, 403, 404, 500).

## Files
- `health.controller.js`: Health-check and API status endpoints.
- `auth.controller.js`: *(Planned Day 3)* Authentication workflows.
- `match.controller.js`: *(Planned Future Phase)* Cricket match retrieval and admin match scheduling.
- `prediction.controller.js`: *(Planned Future Phase)* Toss prediction placement and settlement viewing.
- `wallet.controller.js`: *(Planned Future Phase)* Virtual demo credits ledger, simulated refills, and withdrawal simulations.
