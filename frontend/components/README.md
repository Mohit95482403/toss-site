# Frontend Components Directory (`frontend/components`)

## Purpose
This directory houses reusable HTML template fragments, dynamic JavaScript component renderers, and micro-layouts (such as match cards, prediction modal forms, wallet balance widgets, and alert banners).

## Component Guidelines
- Use Vanilla JavaScript DOM creation or template literals for rendering.
- Keep components decoupled and styled via standard CSS classes from `assets/css/style.css` and `assets/css/variables.css`.
- Ensure keyboard navigability and ARIA accessibility standards across all components.
