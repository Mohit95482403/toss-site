# Frontend Images Directory (`frontend/assets/images`)

## Purpose
This directory stores static images, tournament logos, cricket team crests, and branding assets for TossArena.

## Standards
- Team and tournament badges should be optimized PNG/WebP or SVG files.
- Visual banners must adhere to TossArena's sports theme (deep navy, emerald, gold).
- No placeholder or unauthorized copyrighted third-party betting assets.
